# Retro Design Website

## Project Overview

This project is a retro-themed website designed to showcase classic design elements and aesthetics. The website is built using modern web technologies while maintaining a vintage look and feel.

## Features

- **Responsive Design**: The website is fully responsive and works on all devices.
- **Vintage Aesthetics**: Classic design elements such as retro fonts, colors, and layouts.
- **Interactive Elements**: Includes interactive components like buttons, forms, and animations.
- **Cross-Browser Compatibility**: Works seamlessly across different web browsers.

## Technologies Used

- **HTML5**: For the structure of the website.
- **CSS3**: For styling and layout.
- **JavaScript**: For interactivity and dynamic content.
- **GSAP**: For animations
- **Locomotive JS**: For smooth scrolling in website

## Installation

1. Clone the repository:
    ```bash
    git clone https://github.com/utsavg05/RetroDesign-website.git
    ```
2. Navigate to the project directory:
    ```bash
    cd retro-design-website
    ```
3. Open `index.html` in your preferred web browser.

## Usage

Feel free to explore the website and interact with the various elements. You can also customize the design and content to suit your needs.
