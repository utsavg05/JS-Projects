# Random Joke Generator

This project is a simple web application that generates random jokes. It is built using JavaScript and designed to provide a fun and interactive experience for users.

## Features

- Fetches random jokes from an API.
- Displays jokes dynamically on the webpage.
- Responsive design for various screen sizes.

## Technologies Used

- HTML
- CSS
- JavaScript
- Joke API 

## How to Run

1. Clone the repository:

    git clone https://github.com/utsavg05/Random-Joke.git

2. Navigate to the project directory:
    ```bash
    cd random-joke-generator
    ```
3. Open `index.html` in your browser to view the application.
